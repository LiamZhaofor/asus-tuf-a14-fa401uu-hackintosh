# 驱动（kext）逐个核对

针对本机生成的 EFI，逐个检查了 **20 个 kext / 23 个 Mach-O 可执行文件**。
结论：**未发现缺陷**；有 3 项无法在安装前验证，列在末尾。

---

## 完整性核对

| 校验项 | 结果 |
|---|---|
| 可执行文件架构 | ✅ 23 个全部 **x86_64**，无 ARM 切片、无损坏 |
| 来源版本 | ✅ 全部命中 1401 的 **133 条哈希锁定**（`p1401/mirror.json`），版本与盘上文件一致 |
| 加载顺序 | ✅ `Lilu(0) → AMFIPass(1)`；`VirtualSMC(8)` 先于 `SMCBatteryManager(9)` / `SMCLightSensor(10)` |
| VoodooInput 冲突 | ✅ VoodooI2C 内的 VoodooInput **启用**，VoodooPS2 内的同款 **禁用**（避免重复类） |
| 依赖闭包 | ✅ 每个 kext 的 `OSBundleLibraries` 都能在本套件内解析 |
| 无代码 kext | ✅ `AppleMCEReporterDisabler`（2 个 personality，其中 board-id 列表含 `Mac-27AD2F918AE68F61` = **MacBookPro16,2**，与本机 SMBIOS 吻合）、`UTBDefault`（注入器）—— 二者本就没有可执行文件，属正常 |
| 网卡声明式屏蔽 | ✅ 见文末"ACPI 表加载失败" |

## 具体型号匹配核对（这类"看起来有、其实不生效"最容易踩）

| 部件 | 核对方法 | 结果 |
|---|---|---|
| **声卡 ALC256** | 读 AppleALC 1.9.9 的 Info.plist：现代 AppleALC 把 `HDAConfigDefault`（**663 条**）内嵌在 Info.plist，**不需要 `Resources` 目录** | ✅ ALC256 (`0x10EC0256`) 有 33 条记录，可用 LayoutID 列表 **含 56** → `layout-id 56` 有效 |
| **读卡器** | 读 `Sinetek-rtsx` 的 `IOPCIMatch` | ✅ 含 `0x525A10EC`，正是本机的 `10EC-525A` |
| **无线网卡** | 设备以 `Class_FF`（厂商自定义类）枚举，非 CDC-ECM | ⛔ MT7922 无驱动；且被 SSDT 伪造 ID 屏蔽（但该 SSDT 实际加载失败，见下） |
| **`layout-id` 的数据类型** | 本机是 OpenCore/OpCore-Simplify 写入的**整数 56**，而 Dortania 规范写的是 `Data` | ⚠️ 见下 |

## 三项无法在安装前验证的（诚实列出）

1. **触控板**：ASUS I2C HID（`ASUF1208`）挂在 **AMD** 的 I2C/GPIO 控制器上。
   VoodooI2C 对 AMD GPIO 的支持是这套组合里最没把握的一环，构建里也没有专门的 GPIO 引脚 SSDT，
   只靠 `-vi2c-force-polling`。**键盘是 PS/2（`MSFT0001`）→ VoodooPS2，基本可预期能用**；
   触控板不行就插 USB 鼠标。

2. **`layout-id` 用整数**：AppleALC 源码 `kern_alc.cpp` 读取顺序是
   `alcid= 启动参数` → `alc-layout-id` 属性 → `layout-id` 属性（legacy）。
   若进系统后无声，**在 `boot-args` 加 `alcid=56` 即可**（优先级最高，绕过属性类型问题），
   或把 `layout-id` 改成 `Data`。

3. **没有 CPU 温度/频率监控**：未装 `SMCAMDProcessor` + `AMDRyzenCPUPowerManagement`
   （Zen 4 上不稳定的谨慎取舍）；`Kernel → Emulate → DummyPowerManagement = True` 是 AMD 的标准做法。
   USB 端口映射仍标记为 `mapping_required`，装完系统后用 1401 Mac App 生成 `UTBMap.kext`。

## ACPI 表加载失败（非致命，但值得记录）

```
ACPI Exception: AE_ALREADY_EXISTS, (SSDT:   WLAN) while loading table
ACPI Exception: AE_ALREADY_EXISTS, (SSDT:GpMsSsdt) while loading table
ACPI Exception: AE_ALREADY_EXISTS, (SSDT:  DNET) while loading table
ACPI Error: 3 table load failures, 32 successful
```

- `WLAN` / `GpMsSsdt` 是**固件自带**表，与 DSDT 内同名对象冲突。
- `DNET` 是注入的 `SSDT-Disable_Network_GPP6`，它要写的 `\_SB.PCI0.GPP6.WLAN._DSM` 在 DSDT 里已存在
  → **该 SSDT 从未生效**。由于 MT7922 本就无 macOS 驱动，这张表没有存在价值，可安全删除。
  反之，若将来换上 macOS 原生支持的无线网卡（如 BCM94360NG），也**必须**删除它。
